## 🔴 V2.1 关键修正详解

### 修正1：郁李仁替换桃仁的详细方案

**问题**: V2.0仅简单建议"用郁李仁替换桃仁"，未说明功效差异。

**风险**: 
- 郁李仁活血力仅为桃仁的70%
- 可能导致用户期望的"活血"效果不足

**V2.1解决方案**:
```
提供3种替代方案：

1️⃣ 郁李仁8g（V2.1默认）
   ✅ 润肠通便强（适合便秘+失眠）
   ⚠️ 活血力较弱

2️⃣ 红花3g（如需强活血）
   ✅ 活血力接近桃仁
   ⚠️ 孕妇禁用

3️⃣ 当归10g（如需补血）
   ✅ 补血活血，适合女性
   ⚠️ 孕妇慎用
```

### 修正2：甘草酸精确限量

**问题**: V2.0表述"甘草每日≤5g"不准确。

**风险计算**:
```
V2.0: 3g/包 × 2包/天 = 6g/天
      6g × 5%甘草酸 = 300mg/天
      ❌ 超过限量标准100mg/天 3倍！

V2.1: 2.5g/包 × 5% = 125mg/包
      ✅ 每日1包安全
      ⚠️ 每日2包需医师指导
```

**V2.1措施**:
- 甘草剂量从3g减至2.5g
- 标签明确标注"每日不超过1包"
- 长期服用需监测血压、血钾

### 修正3：苦杏仁苷水解风险控制

**问题**: V2.0未提及郁李仁含苦杏仁苷，未说明水解风险。

**风险**: 
- 苦杏仁苷在湿热+酸性条件下水解
- 产生氢氰酸（剧毒）

**V2.1控制方案**:
```
工艺控制:
  • 提取温度≤80℃（防酶解）
  • 添加碳酸钙0.5%（中和酸性）
  • 喷雾干燥180℃/10s（灭活酶）

检测控制:
  • 每批次检测氰化物残留
  • 标准: ≤1.0mg/kg
  • 方法: GB/T 5009.36

服用建议:
  • 饭后服用（减少胃酸作用）
  • 避免空腹服用
```

## 🚀 使用方式

### 方式1：完整流程（推荐）

```
步骤1: 调用 tcm-food-theory-V2.1
  → 输入配方 → 获得V2.1医理分析报告
  → 确认配方合理性

步骤2: 调用 tcm-food-process-V2.1
  → 输入优化后配方 → 获得V2.1工艺方案
  → 确认生产可行性

步骤3-5: 继续调用 experience/compliance/iteration
```

### 方式2：数据统一管理

所有模块引用 `data/recipe-data.yaml`，确保数据一致性：

```yaml
标准配方(V2.1):
  酸枣仁15g + 郁李仁8g + 黄芪15g + 陈皮3g + 山楂10g + 甘草2.5g
  
安全性标记:
  - 孕妇禁用: ⚠️ 郁李仁破血
  - 限量成分: ⚠️ 甘草酸125mg/包
  - 毒性成分: 🔴 苦杏仁苷0.5%，需控制工艺
```
