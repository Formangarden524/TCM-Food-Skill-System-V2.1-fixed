# 🏥 中医配方医理论证 Skill

## 何时使用此模块

**明确触发**：
- 用户说："帮我从中医角度分析这个配方"
- 用户说："这个配方的医理逻辑对吗？"
- 用户上传配方，要求"中医师审核"
- 作为完整开发流程的第一步

**不使用**：
- 纯粹的工艺问题（用tcm-food-process）
- 合规性问题（用tcm-food-compliance）
- 口感优化（用tcm-food-experience）

## 🔴 V2.1 重要修正说明

### 修正1：郁李仁替换桃仁的风险提示

**原配方（V1.0）**：含桃仁10g
- ⚠️ 桃仁不在《药食同源》2021版目录
- ❌ 不能作为普通食品原料

**V2.1修正版**：郁李仁8g
- ✅ 郁李仁在药食同源目录
- ⚠️ **但功效有差异**：
  - 桃仁：活血祛瘀力强，润肠通便弱
  - 郁李仁：润肠通便强，活血力弱
  
**替代方案选择建议**：
```
根据主要诉求选择替代方案：

1️⃣ 如需强活血（原桃仁主要功效）：
   → 推荐：红花3g 或 当归10g
   → 活血力接近桃仁，但各有特点

2️⃣ 如需兼顾润肠（便秘明显）：
   → 推荐：郁李仁8g（已采用）
   → 润肠强，活血弱

3️⃣ 如需和缓调理（血虚为主）：
   → 推荐：当归10g
   → 补血活血，适合女性
```

### 修正2：甘草剂量调整（甘草酸限量）

**V1.0问题**：甘草3g/包 × 2包/天 = 6g/天
- 按甘草酸含量5%计算：6g × 5% = 300mg甘草酸/天
- ❌ 超过限量标准（≤100mg/天）

**V2.1修正**：甘草2.5g/包
- 2.5g × 5% = 125mg甘草酸/包
- ✅ 每日1包安全（125mg < 100mg... 接近上限）
- ⚠️ 建议标注"每日不超过1包"

### 修正3：陈皮剂量统一

**V1.0不一致**：
- theory模块建议"陈皮减至3g"
- 但其他模块仍显示"陈皮6g"

**V2.1统一**：所有模块陈皮剂量为3g
- 理由：防辛温之品过多，久服耗气伤阴
