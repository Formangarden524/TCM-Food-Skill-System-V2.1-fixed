# 🔄 中医食品迭代验证 Skill

## 何时使用此模块

**明确触发**：
- 用户说："产品上市后如何改进？"
- 用户说："用户反馈有XX问题"
- 用户问："配方需要调整吗？"
- 合规审查完成，产品准备上市/已上市

---

## 📝 输入要求

```yaml
产品信息:
  当前版本: "V1.0"
  已售数量: "500盒"
  上市时间: "30天"

反馈渠道:
  - 电商评论
  - 微信群反馈
  - 客服记录
  - 问卷调查

收集到的反馈:
  - "有点苦"(15人提到)
  - "效果不明显"(8人)
  - "价格偏贵"(5人)
  - ...
```

│问题类型      提及次数  占比  │

    → 影响复购率
  
  • 效果不明显(24%用户反馈)

### 步骤3：配方调整决策树

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【问题 → 解决方案映射】

问题1: 口感太苦(36%用户)
────────────────────────────────
可能原因:
  ☑ 郁李仁苦味重
  ☑ 陈皮苦味突出
  ☑ 甜味剂用量不足

解决方案:
┌────────────────────────────┐
│方案A: 增加甜味剂(推荐)         │
│  赤藓糖醇: 5% → 7%            │
│  罗汉果: 1% → 1.5%            │
│  成本影响: +0.05元/包          │
│  预期效果: 苦味↓50%            │
│                                 │
│方案B: 调整配方                 │
│  郁李仁: 8g → 6g              │
│  陈皮: 3g → 2g                │
│  医理影响: 活血力度↓20%        │
│  需中医师复核                  │
│                                 │
│方案C: 改变剂型                 │
│  颗粒 → 软胶囊                │
│  成本影响: +1.5元/包           │
│  完全掩盖苦味                  │
└────────────────────────────┘

⭐推荐: 方案A(增加甜味剂)
  理由: 成本低,见效快,不改配方

问题2: 效果不明显(24%用户)
────────────────────────────────
深入分析:
  - 这24%用户的共同特征?
    → 查看问卷: 大多数服用<7天
    
  - 可能原因:
    ☑ 服用时间太短
    ☑ 剂量不足
    ☑ 体质不匹配
    ☑ 期望值过高

解决方案:
┌────────────────────────────┐
│方案A: 优化服用指导(推荐)       │
│  - 包装上标注"7天起效"         │
│  - 赠送打卡日历                │
│  - 社群每日提醒                │
│  成本影响: +0.1元/包           │
│                                 │
│方案B: 增加君药剂量             │
│  酸枣仁: 15g → 18g            │
│  成本影响: +0.05元/包          │
│  需验证安全性                  │
│                                 │
│方案C: 增加服用频次             │
│  每日2次 → 每日3次             │
│  包装: 15袋/盒 → 30袋/盒       │
│  价格调整                      │
└────────────────────────────┘

⭐推荐: 方案A(优化服用指导)
  理由: 低成本,直接有效

问题3: 部分用户上火(10%)
────────────────────────────────
深入分析:
  - 上火用户的体质?
    → 查看问卷: 80%是阴虚体质
    
  - 可能原因:
    ☑ 黄芪温补,阴虚者不耐受
    ☑ 陈皮辛温,助火

解决方案:
┌────────────────────────────┐
│方案A: 增加清凉成分             │
│  添加: 菊花3g                  │
│  功效: 清肝明目,制约温燥       │
│  成本影响: +0.03元/包          │
│                                 │
│方案B: 减少温补药剂量           │
│  黄芪: 15g → 12g              │
│  陈皮: 3g → 2g                │
│  医理影响: 补气力度↓20%        │
│                                 │
│方案C: 分体质版本               │
│  推出2个版本:                  │
│  - 标准版(气虚血瘀)            │
│  - 阴虚版(减黄芪,加麦冬)       │
│  成本影响: 研发+5万            │
└────────────────────────────┘

⭐推荐: 方案A(增加菊花)
  理由: 平衡药性,成本低

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
