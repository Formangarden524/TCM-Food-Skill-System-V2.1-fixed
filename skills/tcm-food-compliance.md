## 🔍 审查流程

### 步骤1：企业标准框架

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【企业标准草案】Q/XXX 001-2025

产品名称: XX养生固体饮料
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1 范围
────────────────────────────────
本标准规定了XX养生固体饮料的术语和定义、
技术要求、检验方法、检验规则及标志、包装、
运输、贮存要求。

本标准适用于以酸枣仁提取物、郁李仁提取物、
黄芪提取物、山楂提取物、陈皮提取物、甘草
提取物、赤藓糖醇、麦芽糊精等为主要原料，
经提取、浓缩、干燥、制粒等工艺制成的固体
饮料。

2 规范性引用文件
────────────────────────────────
GB 7101   食品安全国家标准 饮料
GB 7718   食品安全国家标准 预包装食品标签通则
GB 2760   食品安全国家标准 食品添加剂使用标准
GB 2761   食品安全国家标准 食品中真菌毒素限量
GB 2762   食品安全国家标准 食品中污染物限量
GB 2763   食品安全国家标准 食品中农药最大残留限量
GB 5009.3 食品安全国家标准 食品中水分的测定
GB 4789.2 食品安全国家标准 食品微生物学检验 菌落总数测定

3 术语和定义
────────────────────────────────
3.1 固体饮料
以糖、乳和乳制品、蛋或蛋制品、果汁或食用
植物提取物等为主要原料，添加适量的辅料或
食品添加剂制成的粉末状、颗粒状或块状等，
供冲调饮用的固态制品。

4 技术要求
────────────────────────────────
4.1 感官要求

┌────────────────────────┐
│项目        要求              │
├────────────────────────┤
│色泽        棕黄色至棕褐色    │
│滋味气味    微苦,略有酸枣仁香 │
│组织状态    颗粒均匀,无结块   │
│冲调性      易溶于水,无明显沉淀│
└────────────────────────┘

4.2 理化指标

┌────────────────────────┐
│项目             指标         │
├────────────────────────┤
│水分,g/100g      ≤5.0        │
│总黄酮(以芦丁计)  ≥1.5%      │
│                              │
│总皂苷(以酸枣仁   ≥0.8%      │
│皂苷计)                       │
│                              │
│总多糖(以葡萄糖   ≥8.0%      │
│计)                           │
└────────────────────────┘

4.3 污染物限量

按GB 2762执行：
┌────────────────────────┐
│项目        限量(mg/kg)      │
├────────────────────────┤
│铅(Pb)      ≤0.5            │
│总砷(As)    ≤0.5            │
│镉(Cd)      ≤0.1            │
│总汞(Hg)    ≤0.01           │
└────────────────────────┘

4.4 真菌毒素限量

按GB 2761执行:
┌────────────────────────┐
│项目                限量     │
├────────────────────────┤
│黄曲霉毒素B₁        ≤5 μg/kg│
│脱氧雪腐镰刀菌烯醇  ≤1000μg/kg│
└────────────────────────┘

4.5 微生物限量

按GB 7101执行:
┌────────────────────────┐
│项目            限量         │
├────────────────────────┤
│菌落总数        ≤1000 CFU/g │
│大肠菌群        ≤0.92 MPN/g │
│霉菌和酵母      ≤50 CFU/g   │
│                             │
│致病菌:                      │
│ 沙门氏菌       不得检出    │
│ 金黄色葡萄球菌 不得检出    │
└────────────────────────┘

5 检验方法
────────────────────────────────
5.1 感官检验: 目视、嗅闻、品尝
5.2 水分: GB 5009.3
5.3 总黄酮: UV分光光度法
5.4 总皂苷: 比色法
5.5 总多糖: 苯酚-硫酸法
5.6 污染物: GB 5009系列
5.7 微生物: GB 4789系列

6 检验规则
────────────────────────────────
6.1 出厂检验:每批次检验感官、水分
6.2 型式检验:每年至少1次全项检验
6.3 判定规则:全部项目符合本标准为合格

7 标志、包装、运输、贮存
────────────────────────────────
7.1 标签: 按GB 7718执行
7.2 包装: 密封包装
7.3 运输: 避免日晒雨淋
7.4 贮存: 阴凉干燥处,保质期24个月

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

```
⚠️ 慎用:
  - 养生、保健(易引起误解)
  - 调理、改善(需谨慎表述)
  - 滋补、补益(需有依据)

```

```
【生产许可证(SC证)办理】

一、两种方式
────────────────────────────────

  条件:
    ☑ 有生产车间(符合GMP要求)
    ☑ 有检验设备
    ☑ 有质检人员
  周期: 3-6个月
  成本: 2-5万(场地改造+设备)

  条件:
    ☑ 找有SC证的代工厂
    ☑ 签订委托加工协议
    ☑ 自己负责销售
  周期: 无需办理
  成本: 无
  
⭐推荐: 方式B(委托加工)
  99%的初创企业选择代工

────────────────────────────────
必须明确:
  ☑ 产品归谁所有?(委托方)

  ☑ 标签怎么标?(见示例)

标签标注示例:
```
