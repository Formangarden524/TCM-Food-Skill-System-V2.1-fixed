# 😋 中医食品体验优化 Skill

## 何时使用此模块

**明确触发**：
- 用户说："怎么让中药不那么苦？"
- 用户说："这个配方口感会怎样？"
- 用户问："如何提升复购率？"
- 工艺设计完成后的下一步

配方信息:
  成分列表: [已确定的配方]

## 🎨 分析流程

### 步骤1：感官特征预判

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【感官画像分析】

┌───────────────────────────────────┐
│成分    主要呈味  强度  持续性  掩盖难度│
├───────────────────────────────────┤
│酸枣仁  微苦+油腻  4/10  中调    中等  │
│郁李仁  苦+油腻    6/10  后调    较难  │
│黄芪    甘+豆腥    3/10  底味    易    │
│陈皮    苦辛+香    5/10  前调    中等  │
│山楂    酸+甘      8/10  前调    易    │
│甘草    甘         2/10  回味    易    │
└───────────────────────────────────┘

综合感官预判:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
主调: 酸苦为主，伴有药材腥味
前调: 山楂酸味明显(入口)
中调: 陈皮苦辛、郁李仁油腻
后调: 回甘弱(黄芪甘味不足)

问题点:
⚠️ 苦味明显(郁李仁+陈皮),可能20%用户弃用
⚠️ 油腻感(脂肪类成分),影响清爽度
⚠️ 药材腥味(黄芪),降低愉悦度

优势点:
✓ 山楂酸甜,有一定掩盖作用
✓ 甘草回甘,缓解苦味
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

│                   罗汉果      1%    甘甜回味│
│                                               │
│油腻感   酸味提升  柠檬酸      0.3%  清爽感↑ │
│                                               │

│                                               │

│                   甘草提取物  0.5%            │
└────────────────────────────────────────┘

三种风味方案(供测试):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方案A: 微甜型(保留药香)
  - 赤藓糖醇 3%
  - 罗汉果 0.5%
  - 桂花香精 0.05%
  甜度: 5分(10分制)
  适合: 中老年,能接受苦味

方案B: 中度调味(推荐)
  - 赤藓糖醇 5%
  - 甜菊糖苷 0.05%
  - 罗汉果 1%
  - 柠檬酸 0.3%
  - 桂花香精 0.1%
  甜度: 7分
  适合: 大众人群

方案C: 重度调味(完全掩盖)
  - 赤藓糖醇 8%
  - 甜菊糖苷 0.1%
  - 罗汉果 1.5%
  - 柠檬酸 0.5%
  - 水果粉 2%(草莓/桃子)
  甜度: 8-9分
  适合: 年轻人,不耐苦

⭐推荐: 方案B(中度调味)
  理由: 平衡药效与口感,复购率最高
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 步骤3：口感技术优化

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【口感指标设定】

┌──────────────────────────────────┐
│指标        目标值      测试方法      │
├──────────────────────────────────┤
│溶解速度    ≤30秒      80℃水,计时    │
│           (80℃水)                  │
│                                     │
│澄清度      无明显      24h静置观察   │
│           沉淀                      │
│                                     │
│粘稠度      1-3 cP     粘度计        │
│                                     │
│泡沫控制    <2cm       搅拌后观察    │
│           泡沫层                    │
│                                     │
│颗粒均匀度  过20目      筛分法        │
│           >95%                      │
└──────────────────────────────────┘

技术处理措施:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
问题1: 溶解慢
  原因: 颗粒过大或疏水性成分多
  解决: 
    - 颗粒目数↑ (16目→20目)
    - 添加速溶剂(CMC-Na 0.3%)

问题2: 有沉淀
  原因: 提取物溶解度低
  解决:
    - 添加助溶剂(PEG-400 0.5%)
    - 微胶囊包埋油脂成分

问题3: 泡沫多
  原因: 皂苷类成分(黄芪、甘草)
  解决:
    - 添加消泡剂(硅树脂 0.01%)
    - 或标注"泡沫为天然皂苷,可食用"

问题4: 颗粒不均
  原因: 制粒工艺不当
  解决:
    - 优化粘合剂用量
    - 筛分分级
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

│   └─ 否 → 餐后30分钟服用      │
│   ↓                            │
│ 10分钟内饮完                  │
│   ↓                            │
│ 睡前1小时再服1包               │
│   ↓                            │
│ 7天后复盘体感                  │
└────────────────────────────┘

服用便利性清单:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
☑ 独立包装(3g/袋,便于外出携带)

增值体验设计:

1. 包装上印二维码 → 扫码看使用视频
2. 首次购买赠送精美玻璃杯
3. App打卡 → 7天连续送优惠券
4. 晒图分享 → 返现5元
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 步骤5：感官测评设计

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【用户盲测方案】

测试目的: 确定最佳风味方案

招募对象:
  - 人数: 15-20人
  - 年龄: 目标人群(30-40岁女性)
  - 体质: 至少5人是血瘀/失眠体质

测试方法: 9点喜好度标度法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
评分标准:
  9分 = 极喜欢
  8分 = 非常喜欢
  7分 = 喜欢
  6分 = 稍微喜欢
  5分 = 无所谓
  4分 = 稍微不喜欢
  3分 = 不喜欢
  2分 = 非常不喜欢
  1分 = 极不喜欢

测试流程:
┌────────────────────────────┐
│1. 盲编码(A/B/C)               │
│2. 随机顺序品尝                 │
│3. 每次间隔喝清水漱口           │
│4. 填写评分表                  │
│5. 统计分析                    │
└────────────────────────────┘

评价维度:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
| 维度       权重  方案A  方案B  方案C |
|------------|------|-------|-------|-------|
| 整体喜好度  40%   6.2    7.8    7.1  |
| 甜度适中性  20%   7.0    7.5    6.0  |
| 苦味接受度  20%   5.5    7.2    8.5  |
| 溶解速度    10%   7.0    7.0    6.8  |
| 愿意复购    10%   60%    85%    70%  |
|------------|------|-------|-------|-------|
| 加权得分    100%  6.3    7.6    7.1  |

结论: 方案B胜出(得分≥7.5 且复购率>80%)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
